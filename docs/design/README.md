# Laundry HUB — UI design package

Put this whole folder in your project at **`docs/design/`**.

| What | Where |
|---|---|
| Full design spec (tokens, every screen, rules) | `DESIGN_SPEC.md` |
| Screenshot of every screen | `screens/` |
| Clickable prototype (open in a browser) | `prototype/index.html` |
| List of screens (machine-readable) | `screens.json` |
| Original design files | `source/` |

Claude Code: read `DESIGN_SPEC.md` first, then open the PNG and HTML of each
screen before building it. Match text, layout, colors and sizes exactly.

Fonts (DM Sans, Bricolage Grotesque) are included under
`prototype/assets/fonts/files/` and are licensed under the SIL Open Font License.
